我選擇會下雨的漂浮花園，是因為花園不必一直留在原處，也可能自由移動，讓我覺得很有想像空間。我喜歡夢幻又詭異的感覺，希望保留透明薄膜、結晶、漂浮與忽明忽暗的氣氛。相較於現在就決定一隻生物，我想先讓這個會移動的世界成形，之後再延伸到建模與動態。這次選擇先確立了我有興趣的方向，物種的樣子和互動方式還留著發展空間。
