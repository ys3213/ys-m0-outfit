## A｜鹽晶裡的雨季

> 人類消失後 **3,000 年的阿塔卡馬鹽地、舊鹽業蒸發池遺跡**，最大的生存挑戰是 **在短暫濕潤時取得水，又避免被鹽與強光傷害**。

想像一片看起來乾死的半透明晶殼。濕氣到來時，晶殼裡的薄膜才逐層展開；乾燥後縮回裂隙，整片景觀像慢慢閉上眼睛。這是視覺提案，不是現存生物的描述。

| 面向 | 候選條件與證據層級 |
|---|---|
| 時間尺度 | 【藝術創作設定】3,000 年，讓鹽業設施失去原用途、只剩局部地表痕跡；不是宣稱三千年足以演化出特定大型生物。 |
| 地點／棲地 | 【藝術創作設定】以智利 Salar Grande 的鹽地為自然類比，另設一處虛構的舊蒸發池；不能把它當成研究中的真實遺址。 |
| 氣候／物理環境 | 【合理推論】乾旱、多孔鹽殼、間歇濕潤構成生命可活動的時間窗口。三千年後的當地氣候尚無本案證據。 |
| 水 | 【已查證事實 A1】鹽岩內微生物可使用鹽基質從大氣取得的水分；【創作設定】把濕潤事件變成世界的「雨季」，不代表每天準時發生。 |
| 光 | 【已查證事實 A1】研究測得鹽內光合作用；【合理推論】應保留受光與遮蔽的取捨，不把發亮等同自行產能。 |
| 溫度 | 【已查證事實 A1】該研究四天三夜的鹽結核內測量約 8–32°C；只作候選參考，不是全年或未來氣候範圍。 |
| 化學 | 【已查證事實 A1】NaCl 鹽質微棲地；【合理推論】需能處理高鹽與水分流失。 |
| 人造物 | 【藝術創作設定】池埂輪廓、埋藏玻璃碎片與陶瓷片；材質能保存多久仍待專項研究，不設定完整運作的機器。 |
| 最大危險 | 【合理推論】乾燥、強光、鹽度驟變；【創作設定】晶殼反覆溶解／重結晶造成棲所變動。 |
| 潛在能量 | 【已查證事實 A1】光合作用固定碳可支持微生物社群；水和鹽本身不是能源。 |
| 為何適合後未來生命 | 【合理推論】生命可集中於晶殼內少量宜居區；人類留下的直線池格與自然長出的裂紋形成張力。 |
| 未來生命方向 | 【藝術創作設定，未定物種】薄膜群落、可收縮的棲居結構、濕時活動乾時休眠；大型晶體生物是否可行尚未證明。 |

### A 的查證紀錄

**A1 原始研究**：Davila et al. (2015), *In situ metabolism in halite endolithic microbial communities of the hyperarid Atacama Desert*，Frontiers in Microbiology。DOI：10.3389/fmicb.2015.01035。

[已開啟出版社全文](https://www.frontiersin.org/journals/microbiology/articles/10.3389/fmicb.2015.01035/full)

- 實際確認：摘要、環境測量及討論支持鹽岩內有微生物代謝、非降雨水源與光合作用；8–32°C 是短期現場量測。
- SIFT：作者包含 SETI、坎特伯里大學、約翰霍普金斯大學與 CSIC 研究者，方法有現場螢光觀測與實驗室碳固定測試，可追到原研究。不能把文中的「潛在」氨氧化寫成已確定的主要能源。
- 獨立對照 A2：Rothschild et al. (1994), *Metabolic activity of microorganisms in evaporites*，[NASA 保存的原論文摘要與書目](https://ntrs.nasa.gov/citations/20040089558)。另一團隊記錄蒸發岩內微生物的代謝與固碳；不是同一地點，也不證明未來晶體巨獸。只讀到摘要，未取得全文。
- 如何影響設定：活動節奏由水與光控制，晶殼可以是棲地，不能直接把礦物結晶當成生物生長。

## B｜海底的第二片海

> 人類消失後 **10,000 年的阿卡巴灣深海鹵水池邊界**，最大的生存挑戰是 **在有氧海水與高鹽、近無氧鹵水之間，守住一條狹窄的可居住帶**。

想像海底還有一片看起來像液態玻璃的「海」。細薄的棲居層沿著看不見的界面展開，飄過界線就可能失去生存條件。閃光只能是之後另外設計的生物訊號或觀看方式，不是鹵水自然發光。

| 面向 | 候選條件與證據層級 |
|---|---|
| 時間尺度 | 【藝術創作設定】10,000 年，讓地質與沉積的節奏取代人類時間；目前證據不能保證同一鹵水池存續一萬年。 |
| 地點／棲地 | 【藝術創作設定】阿卡巴灣一處以 NEOM Brine Pools 為參照的未來鹵水邊界；【已查證事實 B1】真實池在約 1,770 m 深處。 |
| 氣候／物理環境 | 【合理推論】高壓海底、密度分層；【已查證事實 B1】原研究觀測清楚的鹵水／海水界面。 |
| 水 | 【已查證事實 B1】上覆海水約 40 PSU，鹵水實驗室測值約 160 PSU；是現代 NEOM 測量值，不是未來保證。 |
| 光 | 【合理推論】此深度不能依靠陽光光合作用；研究影像靠探測器照明，不能誤讀成現場有日光。 |
| 溫度 | 【已查證事實 B1】上覆深水約 21.33°C，池內測得增加約 1°C；不是所有深海都接近 4°C，也不是熱泉沸騰池。 |
| 化學 | 【已查證事實 B1】氧在界面下快速下降；作者以近無氧／可能缺氧描述，儀器精度有限，不能精確宣稱氧等於零。 |
| 人造物 | 【藝術創作設定】沉積中的陶瓷與玻璃碎屑；暫不指定仍完整的海纜或供電裝置，保存性待查。 |
| 最大危險 | 【合理推論】跨界的鹽度與氧變化；沉積事件可能掩埋棲所。 |
| 潛在能量 | 【合理推論】沉降有機物與微生物化學代謝；【B1 的研究推論】作者推測界面食物網受化學合成支持，不能寫成已完整測得能量收支。 |
| 為何適合後未來生命 | 【合理推論】世界不必遼闊，幾公分的高度差就可改變生存條件；自然形成視覺與互動的邊界。 |
| 未來生命方向 | 【藝術創作設定，未定物種】沿界面移動、固定在池緣、共生或群聚；不先指定一定是水母或透明魚。 |

### B 的查證紀錄

**B1 原始研究**：Purkis et al. (2022), *Discovery of the deep-sea NEOM Brine Pools in the Gulf of Aqaba, Red Sea*，Communications Earth & Environment。DOI：10.1038/s43247-022-00482-x。

[已取得並閱讀出版社全文](https://www.nature.com/articles/s43247-022-00482-x)

- 實際確認：現場 CTD 與採樣記錄的深度、鹽度、溫度與氧分層；並讀取微生物與大型動物的觀察描述。
- SIFT：論文列出 Miami、KAUST 等研究單位作者及航次來源，使用海床測繪、採樣與化學測量；研究受 NEOM 航次支持，不能只因品牌名稱就推定內容，也不能把不同池的數值混用。
- 獨立對照 B2：[NOAA Ocean Exploration 的墨西哥灣鹵水池探測紀錄](https://oceanexplorer.noaa.gov/multimedia/daily-image-media-20200917/)，說明高鹽鹵水密度較大、沿海底流動與聚集。它支持分層機制，並非 NEOM 的鹽度與溫度資料。
- 如何影響設定：可把「不要跨過某個高度」做成世界規則；鹽度差本身不等於生物已能直接利用的能源。

## C｜會下雨的漂浮花園

> 人類消失後 **500 年的多姆山上空、反覆生成又散去的低層雲霧帶**，最大的生存挑戰是 **在水滴蒸發或落地前延續生命，並重新進入下一片雲**。

想像透明的水滴薄膜像沒有根的花園，隨氣流聚散；美麗的「開花」同時也可能讓它變重，開始墜落。這個世界可以很夢幻，但沒有永遠懸浮、永遠不需要補充能量的島。

| 面向 | 候選條件與證據層級 |
|---|---|
| 時間尺度 | 【藝術創作設定】500 年；選較近未來保留地表遺址的故事，不宣稱已演化出大型飛行生命。 |
| 地點／棲地 | 【藝術創作設定】法國多姆山上空與地表之間的雲霧循環；【已查證事實 C1】原研究採集自 1,465 m 山頂站，不是平流層。 |
| 氣候／物理環境 | 【合理推論】雲滴短暫、隨氣流移動；不能把同一片雲設定為數百年不消失。未來氣候需另查。 |
| 水 | 【已查證事實 C1】研究對象是雲水中的微生物；【藝術創作設定】可在短暫液滴中形成可見薄膜群落，此放大尚無證據。 |
| 光 | 【合理推論】日夜與雲霧遮蔽造成光變化；【藝術創作設定】用透光、閃爍或薄膜色彩表現，不宣稱它們已存在或能靠顏色供能。 |
| 溫度 | 【藝術創作設定，待定案後查氣象】先以接近冰點至涼冷的雲霧情境討論；目前不指定數字，以免把實驗培養溫度當成全年環境。 |
| 化學 | 【已查證事實 C1】雲水包含溶解氣體和顆粒；【合理推論】溶質與氧化壓力可能影響活動，具體濃度未設定。 |
| 人造物 | 【藝術創作設定】地表舊氣象站留下陶瓷／玻璃小碎片作為落地場景；空中不放永久漂浮的鋼鐵城市。遺址保存程度待查。 |
| 最大危險 | 【合理推論】乾燥、降雨移除、強輻射與營養不足。 |
| 潛在能量 | 【合理推論】雲滴中少量有機物可作微生物代謝研究起點；上升氣流提供運輸，不能直接等同生物代謝能源。 |
| 為何適合後未來生命 | 【合理推論】棲地本身不斷消失，生命必須與水循環相連；「漂浮」不只是外觀，而是生存問題。 |
| 未來生命方向 | 【藝術創作設定，未定物種】水滴間傳播、短暫聚落、落地與再升空的生命階段；大型薄膜漂浮體須另驗證浮力、尺度與能量。 |

### C 的查證紀錄

**C1 原始研究**：Amato et al. (2017), *Active microorganisms thrive among extremely diverse communities in cloud water*，PLOS ONE。DOI：10.1371/journal.pone.0182869。

[已開啟出版社全文](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0182869)

- 實際確認：研究對三次雲水事件取樣、分析 DNA／RNA，辨認有活動跡象的微生物類群。不能把這些資料寫成大型漂浮生物已被發現，或所有生命都能在雲中完成繁殖。
- SIFT：作者隸屬 Université Clermont Auvergne、CNRS 等單位；論文有取樣方法、對照與資料存取說明。樣本有限，RNA 指標與直接觀察繁殖不同。
- 獨立對照 C2：Klein et al. (2016), *Molecular Evidence for Metabolically Active Bacteria in the Atmosphere*，[原研究全文](https://www.frontiersin.org/journals/microbiology/articles/10.3389/fmicb.2016.00772/full)。另一團隊在高海拔站採空氣樣本，比較 rRNA／rDNA；支持「可能存在代謝活動」，並明說休眠細胞也可能含核糖體。不是雲中永久繁殖的證明。
- 如何影響設定：把活動窗口、乾燥與落地列為必須面對的規則；需要地表補給的可能性不能省略。
- 讀取紀錄：PMC 版本遇到 reCAPTCHA，因此採用可直接閱讀的 PLOS 出版社版本。

## 最終選擇與原因

本人原話：「漂浮這件事在現實生活不可能存在，所以很有想像空間，代表這個花園可能不在原處，也可能會自由移動。」

整理後的選擇理由：吸引我的是花園不必固定在原地，而可能自由移動的想像空間。

查證修正：現實中雲滴等可以懸浮，不能寫成所有漂浮都不可能。本作品跨向幻想的部分是「整座花園能漂移」；它的物理機制尚未證明。

定案一句話：我的世界是人類消失後 500 年的法國多姆山低層雲霧帶，這裡最大的生存挑戰是棲地隨雲滴蒸發或降雨而消失。

## SIFT 查證方法與紀錄

方法來源：[Mike Caulfield, SIFT (The Four Moves), 2019-06-19](https://hapgood.us/2019/06/19/sift-the-four-moves/)。2026-09-24 已開啟並閱讀作者原文。

- Stop：先確定要查證的主張，不急著採信。
- Investigate the source：確認作者／機構、專業背景及可能立場。
- Find better coverage：找更好的報導或其他獨立研究，記錄一致與不同處。
- Trace：追到原始研究、原圖與上下文，確認測量對象、條件與限制。

每項重要事實將記錄：主張、來源身分、原始來源、獨立對照、實際讀到的內容、不能推論的範圍，以及如何影響世界設定。
