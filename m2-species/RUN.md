# 開啟與展示

優先開啟 [3D 線上作品](https://ys3213.github.io/ys-m0-outfit/m2-species/)。也可直接在瀏覽器開啟 index.html。p5.js 2.0.5 已保存在 lib，附原授權，展示不需連網下載套件。

也可以在 repo 資料夾啟動本機網頁伺服器，再開啟 m2-species。GitHub 原始碼頁不會執行 HTML；線上作品由 GitHub Pages 執行。

## 互動順序

1. 保持水霧模式，移動游標到生命旁停留，帶來水霧，觀察晶瓣展開與個體靠近。
2. 點一下畫布，三個方向的波紋向空間擴散，推開附近個體。
3. 按住 Shift 移動游標，或按「喚起旋風」，觀察旋風讓牠們繞行；再按「讓風停下」關閉。
4. 按「降一場雨」，八秒內整片雲帶補水；飽水個體下沉。多次補水且資源足夠，可看到小個體萌生。
5. 移開游標並等待，水分慢慢減少，花瓣收攏；按「暫停觀察」看形體，按「重新萌生」回到初始花園。

按「轉動視角」後在畫布拖曳，可以看側面與背面；再按「回到水霧」恢復補水。旋轉模式不會觸發滑鼠補水或點擊波紋。滾輪或「遠近」滑桿縮放；「回到正面」恢復正面及原大小。

空白鍵暫停／繼續，R 重置（包含視角）。鍵盤操作時先點畫布；按鈕取得焦點時優先使用按鈕。觸控裝置可點擊波紋與使用按鈕，Shift 旋風需鍵盤；旋轉模式可用單指拖曳，縮放可用滑桿。未宣稱所有觸控裝置皆已測試。

## 讀懂身體

- setup 建立畫布、初始個體與按鈕。
- draw 重複更新後畫出背景、連線、身體、水霧與波紋。
- makeCreature 保存 x、y、z 三維位置、水分、能量與三軸速度。
- updateGarden 用水分控制開合，用力改變位置，用能量門檻控制出芽。
- drawCreature 用立體三角面、橢球與球體畫出五片晶瓣、中央膜囊與核心光點；sin 讓形體緩慢起伏，noise 讓漂移平滑。

## 測試與故障排查

輸入：移動游標、點畫布、按降雨／暫停／重置；輸出：花瓣、位置、水霧、波紋與狀態文字隨之變化。

若只有文字沒有生命，先確認 lib/p5.min.js 與 sketch.js 路徑存在，並查看 browser console 第一個錯誤。請用一般瀏覽器開啟完整資料夾中的 index.html，避免只搬 HTML 而漏掉其他檔案。若動作停住，先查看暫停按鈕；按「繼續漂移」或重置。

所有水分、能量、力與時間門檻是作品參數，不是生理量測結果。


## 3D 測試順序

1. 打開頁面，確認有立體膜囊、晶瓣與感絲；等待可見緩慢轉動、呼吸與前後漂移。
2. 水霧模式下把游標放在一個生物上，觀察展開；點一下觀察空間波紋。
3. 暫停後切到轉動視角，拖曳和縮放；暫停生命時仍能轉動觀看。
4. 回到水霧，繼續漂移，再測旋風與降雨。重置應同時恢復生命、視角、按鈕及縮放值。

如果只有文字沒有 3D，先讀畫面提示及 browser console；確認 WebGL 與瀏覽器圖形加速可用。若只有縮放不會補水，檢查是否仍在轉動視角模式。晶瓣透明材質是視覺呈現，沒有模擬真實光學折射。

需要比較舊版時，開啟 versions/2d/index.html；原 2D 成果保留。
