# 開啟與展示

直接在瀏覽器開啟 index.html 即可。p5.js 2.0.5 已保存在 lib，附原授權，展示不需連網下載套件。

也可以在 repo 資料夾啟動本機網頁伺服器，再開啟 m2-species。不要只在 GitHub 原始碼頁等待動畫；GitHub 檔案頁不會執行 HTML。

## 互動順序

1. 移動游標到生命旁停留，帶來水霧，觀察晶瓣展開與個體靠近。
2. 點一下畫布，波紋向外擴散，推開附近個體。
3. 按住 Shift 移動游標，或按「喚起旋風」，觀察旋風讓牠們繞行；再按「讓風停下」關閉。
4. 按「降一場雨」，八秒內整片雲帶補水；飽水個體下沉。多次補水且資源足夠，可看到小個體萌生。
5. 移開游標並等待，水分慢慢減少，花瓣收攏；按「暫停觀察」看形體，按「重新萌生」回到初始花園。

空白鍵暫停／繼續，R 重置。鍵盤操作時先點畫布；按鈕取得焦點時優先使用按鈕。觸控裝置可點擊波紋與使用按鈕，Shift 旋風需鍵盤。

## 讀懂身體

- setup 建立畫布、初始個體與按鈕。
- draw 重複更新後畫出背景、連線、身體、水霧與波紋。
- makeCreature 保存位置、水分、能量等變數。
- updateGarden 用水分控制開合，用力改變位置，用能量門檻控制出芽。
- drawCreature 畫出五片晶瓣、中央膜囊與核心光點；sin 讓形體緩慢起伏，noise 讓漂移平滑。

## 測試與故障排查

輸入：移動游標、點畫布、按降雨／暫停／重置；輸出：花瓣、位置、水霧、波紋與狀態文字隨之變化。

若只有文字沒有生命，先確認 lib/p5.min.js 與 sketch.js 路徑存在，並查看 browser console 第一個錯誤。請用一般瀏覽器開啟完整資料夾中的 index.html，避免只搬 HTML 而漏掉其他檔案。若動作停住，先查看暫停按鈕；按「繼續漂移」或重置。

所有水分、能量、力與時間門檻是作品參數，不是生理量測結果。
